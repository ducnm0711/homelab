# Workstation

This directory holds setup for my workstation.
Use it to prepare a new laptop.

## Layout

- [setup/](setup/README.md): Base tools, Helm plugins, and the AGE key.
- [shell/](shell/README.md): zsh, Oh My Zsh, Starship, and editor settings.

## Quick start

1. Run the setup steps in [setup/README.md](setup/README.md).
2. Configure the shell in [shell/README.md](shell/README.md).
3. Start the Kubernetes lab when you need it. See [../k8s-lab/README.md](../k8s-lab/README.md).
